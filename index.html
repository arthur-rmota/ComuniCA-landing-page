Algumas respostas para quem está conhecendo o ComuniCA.

O ComuniCA funciona no celular?

Sim. O aplicativo é uma experiência web desenvolvida com foco em smartphones. Basta acessar pelo navegador do celular.

Preciso baixar alguma coisa?

Não. A versão publicada pode ser acessada diretamente pelo navegador, sem instalação obrigatória.

Posso criar meus próprios cartões e frases?

Sim. É possível criar, editar e organizar categorias, cartões e frases rápidas personalizadas.

Minhas personalizações ficam salvas?

Os dados são salvos localmente no navegador do dispositivo. Não há sincronização automática entre aparelhos, e apagar os dados do site pode remover suas personalizações.

O projeto já está finalizado?

O ComuniCA está em desenvolvimento e continua recebendo melhorias. Você pode acompanhar sua evolução no GitHub.
